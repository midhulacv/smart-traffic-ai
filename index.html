How The System Works

01. Image Processing

A camera or recorded video provides traffic footage. Python and OpenCV process the images to identify vehicles.

02. AI Detection

Machine Learning or object detection estimates the number of vehicles and classifies traffic density as low, medium or high.

03. Signal Control

An Arduino Nano or compatible microcontroller controls signal LEDs according to the calculated green-light duration.

Project Overview

AI-Based Smart Traffic Signal System

The project aims to reduce unnecessary waiting time, improve traffic flow and minimize fuel consumption and vehicle emissions through adaptive traffic signal management.

Technologies Used

Python • OpenCV • Machine Learning • Arduino Nano • Image Processing • Embedded Systems

Future Enhancements
