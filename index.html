Project Overview

Understanding the problem and the proposed intelligent solution.

Problem Statement

Conventional traffic signals generally use fixed time intervals without considering the actual number of vehicles on each road. This can waste green-light time on less crowded roads while heavily congested roads experience unnecessary waiting.

Proposed Solution

The proposed system uses a camera or pre-recorded traffic video. Image processing and machine learning are used to detect vehicles, estimate road-wise traffic density and determine suitable signal timing.

Project Objectives

  • Detect and count vehicles on different roads.
  • Classify traffic into low, medium and high density.
  • Allocate green-light time according to traffic density.
  • Reduce unnecessary waiting and prolonged idling.

Expected Benefits

  • Improved traffic-flow efficiency.
  • Reduced unnecessary waiting time.
  • Potential reduction in fuel consumption.
  • Potential reduction in vehicle emissions and air pollution.

Technology and Requirements

Proposed software, hardware and input components.

Software Requirements

  • Python – programming and system logic.
  • OpenCV – image and video processing.
  • Machine learning / object detection – vehicle detection and density estimation.
  • Existing laptop – main processing platform.

Hardware Requirements

  • Arduino Nano or compatible microcontroller.
  • Red, yellow and green LEDs.
  • Resistors and connecting wires.
  • Camera or pre-recorded traffic video as input.
